# Official answer CSV command

From the repository root, using the installed environment:

```powershell
.\.venv\Scripts\python.exe -m src.insights.submission --questions questions.csv --output answers.csv
```

On Linux, replace the Python path with `.venv/bin/python`. Add `--no-llm-cache` to force fresh LLM requests. The command writes exactly `question_id,answer,sql_or_sources,refused`; it preserves input IDs, refuses duplicate or empty IDs, and fails if an answered row has no SQL or sources. DuckDB is limited to 2 GB.

Validation on 4 October 2026 used a generated copy of the 21 released `dev` questions. The [output CSV](step4_dev_answers.csv) has all 21 rows, no non-refused row without evidence, and the answers and evidence match the previous released benchmark exactly. The copy and output were generated by code, not edited by hand.
